# Tab 1a layout grid — 320×480 portrait (backlog a07)

One page, normatively linked from `styles.h`. Tokens in code live in
`styles.h` (`ZMK_GRID_*`, font externs); if doc and code disagree, code wins
— fix the doc the same day.

## Base

- **Unit:** 8 px. Every margin, gap, and widget dimension is a multiple of
  the unit (half-units allowed for text baselines only).
- **Canvas:** 320 wide × 480 tall, portrait, single panel (AXS15231B,
  RGB565, **full-refresh** — see constraints).
- **Safe margin:** 16 px (`ZMK_GRID_MARGIN`) on all four edges. Nothing
  interactive crosses it; the touch controller is less accurate at the
  extremes (bring-up observation, findings §19).
- **Columns:** 40 unit-columns. Screen layouts are named by column spans
  (e.g. hero clock = 24 cols centered).

## Touch

- **Minimum target: 44×44 px** (`ZMK_GRID_TOUCH_MIN`) including spacing.
- **Reach:** the bottom 160 px (`ZMK_GRID_REACH_H`) is the thumb-weighted
  zone — primary actions (a08 nav bar, a10 pomodoro controls, a13 soft keys)
  live there; informational content (a09 clock, a11 stats) sits above.
- Gap between adjacent targets ≥ 8 px (1 unit).

## Type ramp (baked into the generated fonts)

| Role | Size | Face | Style id |
|---|---:|---|---|
| Hero (clock) | 72 | Bai Jamjuree Medium | `ZMK_STYLE_TEXT_HERO` |
| Hero alt | 48 | DM Serif Display | `ZMK_STYLE_TEXT_HERO_ALT` |
| Sub-hero (seconds, timers) | 48 | Bai Jamjuree Medium | `ZMK_STYLE_TEXT_SUBHERO` |
| Title | 28 | Inter | `ZMK_STYLE_TEXT_TITLE` |
| Body | 20 | Inter | `ZMK_STYLE_TEXT_BODY` |
| Caption / hint | 16 | Inter | `ZMK_STYLE_TEXT_CAPTION` |
| Tabular (stats) | 20 | Barlow Medium | `ZMK_STYLE_TEXT_TABULAR` |

Line height = 1.4× size, rounded to the unit where practical. Never call
`lv_obj_set_style_text_font()` with a font outside this table.

## Theme

5 slots (`background, text_primary, text_secondary, accent, inactive`) —
all color comes from the theme through `zmk_display_style()`. Contrast rule:
`text_primary` on `background` ≥ 7:1, `text_secondary` ≥ 4.5:1 (WCAG AA at
arm's length); the three built-in presets satisfy this — measure any new
preset with the same bar.

## Panel constraints that shape the grid

- **Full-refresh panel ≈ 16 fps ceiling** (risk R5): animated art authored
  ≤ 15 fps; every screen carries a measured FPS budget in its a09-a13 item.
- 16-bit RGB565: banding on large gradients — prefer flat fills per slot.
- LVGL pools live in PSRAM (`cobantab1a.conf`): keep per-screen object counts
  modest; no thousands-of-objects layouts.

## Font provenance (pipeline)

Generated by [`../../../scripts/display-fonts/gen_fonts.sh`](../../../scripts/display-fonts/gen_fonts.sh)
(lv_font_conv 1.5.3, bpp 2, no compression) from google/fonts:

| Face | File in google/fonts | License |
|---|---|---|
| Bai Jamjuree Medium | `ofl/baijamjuree/BaiJamjuree-Medium.ttf` | OFL 1.1 |
| DM Serif Display | `ofl/dmserifdisplay/DMSerifDisplay-Regular.ttf` | OFL 1.1 |
| Inter (variable) | `ofl/inter/Inter[opsz,wght].ttf` | OFL 1.1 |
| Barlow Medium | `ofl/barlow/Barlow-Medium.ttf` | OFL 1.1 |

sha256 of each cached TTF is recorded next to it in the script's `.cache/`.
An icon face (FontAwesome5 subset, pad10a-style) is deferred to a08+ when the
first glyph is actually needed. Hero faces are digit/punctuation subsets
(`0123456789:./-%+ AMP`); UI faces carry full printable ASCII.
